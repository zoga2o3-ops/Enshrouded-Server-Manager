# Changelog

## 0.9.2

### Live map
- The live map ships inside the app. When you add a server (install or add an existing folder), the map is installed into it automatically.
- Existing servers: use **Install live map** (or **Reinstall live map**) on the server's Overview. Stop the server first.
- New **Map** tab shows the live map inside the app while the server is running.
- The Overview's Live map panel shows the install status and the share link, with a copy button. Share the link with friends so they can watch the map. Anyone with the link can see where every player is.
- Players appear by name on the map.

Live map mod by oggii (https://github.com/oggii/enshrouded-livemap, MIT). Map art and icons © Keen Games.

### Server password
- The **Password** field now sets the join password. It is stored on the user group that players join with when they enter no password (the Friends group). The Admin group keeps its own password.
- Clear the field and save to make the server public again.
- Restart the server after saving for the change to take effect.

### Settings
- **Save settings** is in a bar at the top of the server's Settings tab and the global Settings page, and stays in view while you scroll.
- The client version shows as v0.9.2 in the footer.
